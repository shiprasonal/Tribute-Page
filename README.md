# 🕊️ Tribute Page: Dr. A. P. J. Abdul Kalam

A responsive tribute page dedicated to **Dr. A. P. J. Abdul Kalam**, the scientist and 11th President of India, built using **HTML, CSS, and JavaScript**. It tells his story through a short biography, a milestone timeline, and a quote section.

## ✨ Features

- Page title with the subject's name and a one-line tagline.
- Prominent portrait sourced from Wikimedia Commons, with a credit caption.
- Biography section with four paragraphs written in my own words.
- Timeline of key milestones (1931 to 2015) built with an ordered list and styled cards.
- Distinctly styled quote block with a "Show another quote" button.
- Multiple background colours across sections (navy, cream, sand).
- Two font styles: Playfair Display (serif) for headings and Nunito Sans (sans-serif) for body text.
- Scroll progress bar and timeline cards that fade in while scrolling.
- Fallback placeholder if the portrait fails to load.
- Responsive design for different screen sizes.

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure and layout |
| CSS3 | Styling, CSS Grid, and responsive design |
| JavaScript | Scroll progress bar, reveal animation, and quote switcher |
| Google Fonts | Playfair Display and Nunito Sans |

## Installation

Clone the repository using the following command:

```
git clone https://github.com/shiprasonal/Tribute-Page.git
```

Open the cloned project folder and launch `index.html` in your web browser. An internet connection is needed to load the portrait and Google Fonts.
